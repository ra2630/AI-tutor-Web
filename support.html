In-App Problem Reporting

For the fastest resolution of a specific problem or lecture step, use the Report a problem option inside the Mentor AI app.

It prepares an addressed email draft populated with the exact course identifier, lecture title, question number, and app version so we can inspect the exact learning state immediately. You can review the full text of the draft before sending.

Useful Details to Include in Manual Reports

If contacting us directly by email, the following details help us diagnose the issue quickly:

• The specific course and lecture title (e.g., Quadratic Equations · Lecture 04)
• The question number or practice module
• Your device model and operating system version (iOS or Android)
• What you expected to occur vs. what happened

Privacy & Security Note

Our in-app diagnostic reports never attach notebook photographs, passwords, or personal identity details automatically. Please do not send passwords or payment information via email.

Course Release Inquiries

For questions about the release roadmap for JEE Physics, JEE Chemistry, CBSE Classes XI & XII, or planned standardized exams (NEET, SAT, GRE, GMAT), please write to info@mentoraistudy.com.
